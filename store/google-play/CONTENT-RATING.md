# DataLux content-rating record

> **Status:** IARC questionnaire completed in Play Console; app review and release remain pending
> **Owner:** Product / release engineering
> **Last reviewed:** 2026-10-29

The owner approved accepting the IARC Terms of Use and sharing the existing support address
`fileflowsupport@gmail.com` with IARC/rating authorities. The questionnaire was completed for
DataLux (`dev.datalux`) on October 29. Console shows **IARC status: Completed**. This does not
publish the app, finish Google review, or enable another release country.

## Submitted answers and rationale

| Question | Answer / basis |
| --- | --- |
| Category | All Other App Types: a file-transfer utility |
| Ratings-relevant bundled content | No: no bundled violence, sex or strong-language content |
| Native user content exchange | Yes: users can send their own files directly through DataLux |
| Shared user content is primary content | Yes: received/shared files are user supplied; no developer content catalog |
| Public sharing of nudity / graphic violence | No: no public feed, upload service or content-discovery community is provided |
| User/content blocking, reporting, chat moderation | No: do not claim moderation tools that the app does not implement |
| Interactions can be limited to invited friends | Yes: encrypted pairing and invited teams restrict who can decrypt transfers |
| Promoted online content | No: no streaming, news, shopping or generated-content catalog |
| Age-restricted products or activities | No |
| Current precise location shared with users | No |
| Digital purchases | Yes: Android Pro is an in-app purchase |
| Randomized purchases / cash rewards / transferable digital assets | No |
| Browser/search engine; primarily news/education | No |

The public-sharing answers describe the app's services, not a claim that arbitrary file bytes
are inspected or filtered. Plain optical transmissions can be observed by nearby cameras;
use encrypted pairing/teams for confidential handoffs. Revisit these answers if a hosted feed,
public discovery, chat, moderation, location sharing or another content service is added.

Google's definitions include native exchange of user-created content; sharing only via another
app is distinct. See [User Content](https://support.google.com/googleplay/android-developer/answer/11070862)
and [primary user content](https://support.google.com/googleplay/android-developer/answer/12994051).

## Remaining audience dependency

The target-audience form is blocked in Console until **Sign in details** is complete. Pro and
companion-device use must be declared restricted. Complete it with a legitimate, preverified
reviewer account and rehearsed instructions after the deferred server setup; do not claim all
features are unrestricted or submit placeholder credentials. DataLux is a general-purpose utility,
not a product designed for young children. Audience selection must match the final product and
marketing, independently of the calculated content rating.

See [Google content ratings](https://support.google.com/googleplay/android-developer/answer/9859655),
[target audience](https://support.google.com/googleplay/android-developer/answer/9867159),
[reviewer instructions](en-US/README.md#reviewer-access-draft--fill-privately-in-console), and
[NUC handoff](NUC-HANDOFF.md).
